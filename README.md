# E-Commerce Customer Funnel & Conversion Analysis

## Project Overview
This project uses MySQL to analyze e-commerce user behavior, track customer progression through the purchasing funnel, and evaluate marketing channel performance.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Analysis Performed
1. **Customer Funnel Analysis:** Analyzed user progression from page views to cart additions and purchases.
2. **Conversion Rate Analysis:** Calculated conversion rates across different stages of the purchasing funnel.
3. **Marketing Channel Analysis:** Compared organic, paid ads, social, and email traffic sources.
4. **Time-to-Conversion Analysis:** Measured the average time between customer interactions and purchases.
5. **Purchase Analysis:** Analyzed purchasing activity using SQL aggregations.

## SQL Concepts Used
- Common Table Expressions (CTEs)
- CASE WHEN
- COUNT and COUNT DISTINCT
- GROUP BY and HAVING
- Aggregate functions
- TIMESTAMPDIFF
- Conversion rate calculations
